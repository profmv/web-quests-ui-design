# L001 — Arquivos de governanca (licoes, diario, handoff, agents) devem residir na pasta do projeto atual

## Regra

Criar e manter docs/licoes, docs/diario, docs/handoffs e AGENTS.md estritamente na pasta raiz do projeto atual, nunca na raiz de repositórios ancestrais

## Contexto

O usuario estabeleceu a regra obrigatoria de manter toda governanca, diario, licoes e handoffs confinados na pasta do projeto
